# AltOS flight logs

Sixteen TeleMetrum flight logs from AltOS, the Altus Metrum firmware,
copied unmodified from `src/kalman/` of AltOS 1.9.22 (Debian source package
`altos` 1.9.22-3, https://altusmetrum.org/AltOS/).
